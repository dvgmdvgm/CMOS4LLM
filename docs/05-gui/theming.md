# GUI: Theming

> Dark theme as default. Dense, professional, low-distraction.

## Default Theme

- Dark background, high-contrast text
- Monospace headings, system sans-serif body
- Accent colors for status (green=healthy, amber=warning, red=violation)
- Minimal borders, subtle separators
