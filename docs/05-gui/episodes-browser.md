# GUI Screen: Episodes Browser

> Linear/Jira-like interface for browsing completed tasks as case studies with reasoning trails.

## Purpose

Each episode = a completed task with full context: what was asked, what was retrieved, what was decided, what was learned. Enables pattern recognition across past work.
