# /wake — принудительный wake-up ритуал

Используется когда:
- Owner возвращается после длинной паузы внутри сессии и хочет «перепроверить» контекст.
- В новой сессии CLAUDE.md по какой-то причине не сработал автоматически.
- Owner хочет явно увидеть актуальное состояние проекта перед продолжением.

## Что делать

1. Прочитай `D:\AI Projects\CMOS\STATUS.md` (целиком).
2. Прочитай `D:\AI Projects\CMOS\NEXT.md` (целиком).
3. Найди и прочитай **самый свежий** файл в `D:\AI Projects\CMOS\docs\09-conversation-log\` (сортировка по имени файла, формат `YYYY-MM-DD-*.md`).
4. Проверь `D:\AI Projects\CMOS\ROADBLOCKS.md` — есть ли активные вопросы, блокирующие следующий шаг.
5. Доложи owner'у одним абзацем (3-6 строк):
   - Текущая фаза проекта + % готовности.
   - Что сделано в прошлой сессии (1-2 ключевых артефакта).
   - Следующий шаг по `NEXT.md` (формулировка из файла).
   - Активные блокеры, если есть.
6. Если owner не дал явной команды на действие — спроси: «Берёмся за пункт N или другой план?». Если дал (например триггер-фразу «продолжаем») — приступай к первому незакрытому пункту из NEXT.md без переспроса.

## Что НЕ делать

- Не пересказывай весь README — он скучный и owner его уже видел.
- Не предлагай менять scope без явной просьбы.
- Не начинай работу без подтверждения, если первое сообщение не содержит триггер-фразы.
